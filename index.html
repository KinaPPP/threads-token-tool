🧵 Threads API トークン取得ツール

セキュリティについて
App ID・App SecretはMetaの公式APIとの認証に使用します。このページにKINA管理の認証サーバーはありません。 認証コードやトークンを含むURL、開発者ツールの通信ログは公開しないでください。 この版では長期トークン交換だけ、お使いのPCのPowerShellで実行します。

Meta for Developersで取得した、ご自身のThreads App IDとApp Secretを入力してください。MetaのOAuthコールバックURLは従来のまま変更不要です。

要求権限：threads_basic / threads_content_publish / threads_profile_discovery

Threadsから短期トークンを取得しています… ⏳

✅ 短期トークンを取得しました

ブラウザではMeta側のCORS制限により、長期トークン交換の結果を読み取れません。長期交換はローカルのPowerShellで行います。新たな外部認証サーバーは不要です。

長期トークンへの交換（Windows）
  1. この画面の短期トークンをコピーする。
  2. 同じリポジトリにある threads-long-token.ps1 をダウンロードし、内容を確認してPowerShellから実行する。
  3. 求められたら、ご自身のApp Secretと短期トークンを貼り付ける。入力は非表示で、Meta公式APIにのみ送信される。
  4. 表示された長期トークンと、上記のUser IDをクロスポストまたはシンプルまるごとZIPに登録する。
PowerShell補助ツールを保存

PowerShellの実行ポリシーにより.ps1が実行できない場合は、「補助ツールのコードをコピー」してPowerShellに貼り付けてください。コードを確認してから実行してください。
